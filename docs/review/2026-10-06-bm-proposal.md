## 1. 문제: 이 앱은 가치가 앱 밖에서 생긴다

| 사용자가 가치를 느끼는 순간 | 어디서 | 광고를 넣을 수 있나 |
|---|---|---|
| 유튜브를 열려다 "돈 벌어야지."를 본다 | 다른 앱 위(확인 화면) · **하루 여러 번** | 🚫 Play 광고 정책 *"inside of the app serving them"* (직접 확인 · CLAUDE §7.1) |

## 3. 숫자로 본 차이 (🔴 자릿수만 보는 추정)

가정: 설치 1만 · 한국 위주 · Play 수수료 15% · 광고 단가는 배너 약 $2(에이전트 수집 · 출처 방법 불명 · 추정), 보상형 $12(배구명가 `MONETIZATION_SYSTEM.md` · Appodeal 2024 Q4).

| 방식 | 계산 | 1만 설치당 |
|---|---|---|
| 홈 배너만 | 활성 사용자가 한 달에 홈을 몇 번 볼까: 규칙을 다 만든 뒤 **월 4회 · 회당 1노출**(추정) × 활성 50% | 월 약 ₩5만 |

| 평생 Pro ₩9,900 | 전환 2% × ₩9,900 × 85% | **한 번에 약 ₩168만** |

→ 광고는 **배너를 다 붙여도 결제 몇 건과 비슷하다.** 광고는 "주 수입"이 아니라 **무료 사용자에게 Pro 를 맛보게 하는 장치**로 쓰는 편이 낫다.

## 4. 제안 구조: 무료 핵심 + 평생 Pro(일회성) + 보상형 광고는 보조

```
무료 ── 실행 전 확인 1개 + 실행 확인 1개 ──┬─▶ [광고 보고 규칙 칸 +1] (최대 +2 · 영구)
     (대상 앱 수 · 메시지 · 시간 조건은 그대로)  │
                                            └─▶ Pro 평생 ₩9,900(출발값) ── 규칙 무제한 + Pro 기능
```

### 4.1 무료 (기획서 §26 의 "무료" 목록 그대로)

- 실행 전 확인 **1개**(대상 앱은 여러 개 가능 · 기획서 §5 "업무시간" 한 규칙이 그대로 된다) + 실행 확인 **1개**.
- 직접 쓴 메시지 · 요일 · 시간. 핵심 동작은 하나도 빼지 않는다.
- 🔴 **두 번째 규칙을 만들 때** 페이월이 뜬다. 기획서 §31 의 하루(업무시간 + 야식 방지 + 일기)를 다 하려면 여기서 고른다: 광고 보기 · Pro.

### 4.2 보상형 광고 = 규칙 칸 +1 (영구 · 최대 +2)

- 사용자가 고른 사람만 본다(질문하신 "보상형" 방향). 이 앱 안 · 규칙 만들기 화면에서만 · 확인 화면 · 알림과는 무관.
- **영구 칸**으로 준다. 시간제 체험은 끝나면 규칙이 멈춰야 하는데, 그건 이미 만든 것을 잠그는 **인질 모델**이다(Re:Read §2.2 원칙 *"이미 저장한 것은 절대 잠그지 않는다"*).
- 최대 +2 로 막아 "규칙 무제한"은 Pro 에 남긴다. 무료 최대 4개(1+1+2)면 기획서 §31 의 하루는 광고 두 번으로 된다.
- 수익보다 **"무료로도 끝까지 쓸 수 있다"** 는 신뢰가 목적이다. 광고 수익은 위 표대로 작다.

### 4.3 Pro 평생 ₩9,900 (출발값 · placeholder 2026-10-06)

| Pro 기능 | 출처 | MVP 비용 |
|---|---|---|
| 규칙 무제한 | 기획서 §26 | 개수 검사 하나 |
| 랜덤 메시지 · 메시지 여러 개 | 기획서 §26 · §27(*"메시지가 익숙해지는 문제를 줄인다"*) | 작다(메시지 목록 + 무작위 선택) |
| 다시 알림(30분 뒤 한 번) | 기획서 §16 · §26 | 작다(알람 하나 더) |
| 이후: 행동 연결 · 주간 리포트 · 고급 통계 · 백업 · 복수 시간대 · 테마 | 기획서 §26 · §28 | 출시 후 Pro 가치를 키우는 자리 |

- 가격 근거: one sec **1년 값($19 ≈ ₩27,000)보다 싸고**, Vivace 광고 제거(₩3,300 · 기능 없음)보다 비싸다. 한국 루틴 앱 평생가(₩69,000 ~)는 브랜드가 있는 앱이라 참고만. 출시 후 전환율로 조정한다.
- **배너는 없다(추천).** 위 계산상 수익이 작고, "집중하려고 설치한 앱"의 홈에 상시 광고를 두는 대가가 더 크다. 홈은 규칙 목록 하나뿐이라 배너가 화면을 크게 차지한다.

## 5. 앱을 다시 열게 만드는 장치 (선택 · 기둥과의 긴장 있음)

광고 · 결제 모두 "앱을 여는 횟수"가 적다는 문제는 남는다. 열 이유를 하나 만들 수는 있다.

- **주간 요약 알림**(일요일 저녁 1회 · 기본 꺼짐 · 사용자가 켠다): *"이번 주 확인 18번 · 그대로 연 10번 · 일기 6/7일"* → 누르면 이 앱의 주간 화면.
  - 이득: 주 1회 자연스러운 방문 = Pro 기능(주간 리포트 상세)을 보여 줄 자리.
  - ⚠ 긴장: 기둥 3(필요한 순간에만) · 기획서 §18(*"통계는 보조, 주인공으로 만들지 않는다"*) · 미결정 G. 그래서 **기본 꺼짐**, 숫자만 보여 주고 칭찬 · 비난 문구 없음(기둥 2).
  - 추천: MVP 에는 넣지 않고 Pro 확장 1순위로 둔다.
