# DISTRIBUTION_POLICY — 배포 국가 (결정 #14)

## 1. 지금

- **145개국.** Play 가 고를 수 있는 나라 중 **유럽경제지역(EEA) 30개국 · 영국 · 스위스 = 32개국을 뺀 전체**(목록은 `PRE_LAUNCH_CHECK.md` §1 "닫는 32개국").
- 언어: 영어(기본 · `en`) + 한국어(한국어 기기는 `ko`).
- 비공개 테스트 트랙도 같은 국가로 둔다.

## 2. 왜 32개국을 닫나

- 처음(2026-10-06)의 이유는 **광고 동의(UMP)가 없어서**였다. 결정 #16(광고 없음)으로 그 이유는 사라졌다.
- 지금의 이유(2026-10-08 다시 물음 · 선택 "처음엔 닫고 나중에"): **데이터를 많이 모으는 만큼 GDPR 부담이 크다**(결정 #21 · #22 · #24 · #30). 접근성으로 얻은 대상 앱 이름 · 사용 통계 · 사용자가 쓴 메시지 원문을 서버에 모은다.
  GDPR 로 열면 처리 근거 · 동의 · 처리방침 GDPR 절 · 만 16세 기준 · 국외 이전 근거를 새로 갖춰야 한다.
- 대가: 유럽 사용자를 처음엔 받지 못한다.

## 3. 열 때 순서

1. 처리방침 GDPR 절(처리 근거 · 권리 · 국외 이전) 작성 · 게시.
2. 연령 기준(만 16세)과 동의 흐름 결정 · 구현(광고가 없으므로 UMP 는 필요 없다).
3. 콘솔에서 32개국 추가.
4. 이 문서와 CLAUDE 결정 #14 를 고친다.
